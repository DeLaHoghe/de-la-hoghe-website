# De La Hoghe Chapter No. 1089

Four-page static website for the Rose Croix Chapter in the District of West Cheshire.

## Netlify

Import this repository, choose the main branch, leave the build command empty, and set the publish directory to `dist`. The included netlify.toml also sets the publish directory.

## Pages

- Home
- About Rose Croix
- Meetings and visits
- Joining and enquiries

The enquiry form uses Netlify Forms. After deployment, enable form detection in Netlify and verify that the joining-enquiry form is listed. Configure email notifications privately in Netlify if required. No recipient email address is stored in this repository.
